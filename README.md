### Student-manager-system

A simple command-line based Student Manager system built using Python.
This project allows users to add students, view student data, and check results.

---

## 🚀 Features

* ➕ Add student with marks
* 📋 View all students
* 📊 Check pass/fail result
* ❌ Exit program

---

## 🛠️ Technologies Used

* Python
* Basic Data Structures (Dictionary)

---

## 📌 How It Works

1. User selects an option from menu:

   * Add Student
   * View Students
   * Check Result
   * Exit

2. Data is stored in a Python dictionary.

3. Pass condition:

   * Marks >= 40 → Pass
   * Marks < 40 → Fail
